# Generated Outputs

This folder contains structured evaluation outputs generated by the FundFirst modelling notebook.

Unlike the figures stored in [`../results/`](../results/), these files preserve the underlying model predictions, evaluation metrics and income-stratified audit results in machine-readable CSV format.

## Files

| File | Description |
|---|---|
| [`model_test_results.csv`](model_test_results.csv) | Held-out Accuracy and Macro-F1 results for Logistic Regression and Random Forest |
| [`test_predictions.csv`](test_predictions.csv) | Row-level 2024–2025 true feasibility labels and predictions from both evaluated models |
| [`bias_audit_accuracy.csv`](bias_audit_accuracy.csv) | Logistic Regression accuracy by higher- and lower-income borough groups |
| [`bias_audit_precision.csv`](bias_audit_precision.csv) | Per-class precision and predicted-case counts for each income group |
| [`bias_audit_precision_gaps.csv`](bias_audit_precision_gaps.csv) | Between-group class precision gaps and predefined 10 percentage-point investigation flags |

---

## Held-Out Model Results

The final evaluation uses the **2024–2025 held-out period**, containing **12 borough-year observations**.

[`model_test_results.csv`](model_test_results.csv) records the headline model comparison:

| Model | Accuracy | Macro-F1 |
|---|---:|---:|
| **Logistic Regression** | **0.833** | **0.778** |
| Random Forest | 0.583 | 0.444 |

Logistic Regression produced the strongest held-out performance and was selected as the final model.

---

## Test Predictions

[`test_predictions.csv`](test_predictions.csv) contains the individual predictions for every observation in the held-out test set.

The file includes:

- `Borough`
- `Year`
- `FeasibilityTier`
- `LogisticPrediction`
- `RandomForestPrediction`

This makes the aggregate evaluation metrics traceable back to individual borough-year predictions.

---

## Income-Stratified Accuracy Audit

[`bias_audit_accuracy.csv`](bias_audit_accuracy.csv) contains accuracy results for the two income groups used in the exploratory performance audit.

| Income Group | Accuracy | Number of Cases |
|---|---:|---:|
| Higher Income | 0.667 | 6 |
| Lower Income | 1.000 | 6 |

The resulting accuracy difference is approximately **33.3 percentage points**.

Because each group contains only six observations, this result is treated as an investigation signal rather than evidence of systematic unfairness.

---

## Class Precision Audit

[`bias_audit_precision.csv`](bias_audit_precision.csv) records precision by feasibility class and income group.

The largest measurable difference occurred for the **Stretch** class:

- Higher-income precision: **0.333**
- Lower-income precision: **1.000**
- Precision gap: **0.667**
- Gap in percentage points: **66.7 pp**

For the Unfeasible class, no lower-income observations were predicted as Unfeasible, so precision is undefined for that group rather than zero.

---

## Precision Gap Flags

[`bias_audit_precision_gaps.csv`](bias_audit_precision_gaps.csv) applies the project's predefined **10 percentage-point investigation threshold**.

| Class | Gap | Flag |
|---|---:|---|
| Achievable | 0.0 pp | No |
| Stretch | **66.7 pp** | **Yes** |
| Unfeasible | Not measurable | No |

These flags identify areas requiring further investigation.

They should not be interpreted as proof of discrimination because the analysis is based on:

- a small 12-row held-out test set
- aggregate borough-level observations
- income as a socioeconomic proxy
- no individual-level protected-characteristic data
